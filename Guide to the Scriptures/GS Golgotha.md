# Golgotha

[Link](https://www.churchofjesuschrist.org/study/scriptures/gs/golgotha?lang=eng)

*See also* [[GS Crucifixion|Crucifixion]]; [[GS Jesus Christ|Jesus Christ]]

*Golgotha* means “a skull” in the Aramaic language. It is the name of the place where Christ was crucified ([[Matthew 27.33|Matt. 27:33]]; [[Mark 15.22|Mark 15:22]]; [[John 19.17|John 19:17]]). The Latin name for this place is Calvary ([[Luke 23.33|Luke 23:33]]).
