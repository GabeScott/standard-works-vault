# Gerar

[Link](https://www.churchofjesuschrist.org/study/scriptures/bd/gerar?lang=eng)

A place in southwestern Palestine, near Gaza ([[Genesis 10.19|Gen. 10:19]]). Abraham lived there for a time ([[Genesis 20.1|Gen. 20]]), as did Isaac ([[Genesis 26.1|Gen. 26]]). See also [[2 Chronicles 14.13|2 Chr. 14:13–14]][[2 Chronicles 14.14|]].
