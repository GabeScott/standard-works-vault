# Race

*See also* [[Run, Ran.md|Run, Ran]]

*race* is not to the swift, [[Ecclesiastes 9.11|Ecclesiastes 9:11]].

they which run in a *race* run all, [[1 Corinthians 9.24|1 Corinthians 9:24]].

let us run with patience the *race*, [[Hebrews 12.1|Hebrews 12:1]].

from Ham, sprang that *race* which preserved the curse in the land, [[Abraham 1.24|Abraham 1:24]].
